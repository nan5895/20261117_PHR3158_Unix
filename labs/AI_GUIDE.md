# 🤖 AI 사용 가이드 (1분 요약)

AI는 **설명해 주는 조교**입니다. 대신 해 주는 사람이 아닙니다.
요즘 AI 도구(Copilot, Claude Code 등)는 실제로 **셸 명령을 실행**합니다. 셸을 읽을 줄 알아야 "실행해도 될까요?" 에 답할 수 있습니다.

## 1. 순서: 예측 → 실행 → 설명 → AI
내가 먼저 예측하고 실행해 본 뒤, **설명이 안 되는 부분만** AI에게 묻습니다.

## 2. 질문할 때 파일 앞부분을 같이 보여주기
AI가 틀리는 가장 흔한 이유는 **파일을 못 봤기 때문**입니다.
```
Ubuntu bash 를 쓰고 있어. samtools flagstat 결과가 이래:
(결과 붙여넣기)
각 줄이 무슨 뜻인지 설명해 줘.
```

## 3. 검증하기
- 다른 방법으로 한 번 더 확인하기 (예: Lab 1 의 align.sh 결과와 Lab 2 의 BWA 결과가 같은 위치인지)
- 작은 예제를 손으로 계산하기
- `man 명령어`, `명령어 --help` 로 옵션 확인

## 4. 실행 전 3초 점검 ✋
`rm` · 이미 있는 파일에 `>` · `sudo` · `curl ... | bash` 가 보이면 **멈추고 물어보기**.
지우기 전에는 `ls` 로 대상부터 확인.

## 5. 유전체 데이터는 민감정보 🔒
이 수업 데이터는 가상 데이터라 괜찮지만, **실제 환자 유전체·임상 데이터는 외부 AI에 절대 붙여넣지 않습니다.**
